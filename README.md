# The Interpreted Harness

**Christopher Maglio and Muse** — 24 October 2026

[Read the paper (PDF)](Interpreted_Harness.pdf)

This paper defines the interpreted harness — a multi-agent architecture in which a natural-language protocol document, interpreted by two complete and independent AI agents over a shared message board, replaces the compiled agent loop. It sets that architecture against production harnesses such as OpenClaw, tracing how OpenClaw grew from a one-hour WhatsApp relay into a loop-closing gateway, and it argues the interpreted harness's decisive superiority: not that it writes better prompts, but that it no longer needs them. A compiled harness survives only prompts engineered to precision, because one interpreter executes a prompt's defects as faithfully as its intent. The interpreted harness reconciles two independent interpretations of the same goal, so the operator may write the goal as goals are actually written — rough, incomplete, and partly wrong — and still get a result better than the prompt deserved.

The relay hardware and protocol analyzed in the paper live in [AI_Relay](https://github.com/christophermaglio/AI_Relay).
